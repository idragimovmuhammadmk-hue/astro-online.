# ASTRO ONLINE

Это уже не локальная версия: аккаунты, рейтинг, баланс, XP, ранги и квесты хранятся на общем PostgreSQL-сервере. Изменения рейтинга отправляются всем подключённым клиентам через Socket.IO и дополнительно проверяются каждые 2 секунды.

## Запуск
1. Установи Node.js 18+.
2. Создай PostgreSQL базу данных.
3. Скопируй `.env.example` в `.env` и заполни `DATABASE_URL` и `JWT_SECRET`.
4. В этой папке выполни `npm install`.
5. Выполни `npm start`.
6. Открой `http://localhost:3000`.

## Чтобы друг зашёл
Сервер должен быть доступен из интернета (например, через Render/Railway/Fly.io/VPS) и иметь PostgreSQL. После публикации друг открывает публичный адрес сервера и регистрируется там.

## Важно
Не публикуй `.env` и не оставляй стандартный JWT_SECRET. Пароли хранятся в базе в виде bcrypt-хэшей.
